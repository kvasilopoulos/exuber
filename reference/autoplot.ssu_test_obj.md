# Plot method for ssu_test() output

Plots the recursive SSU statistic path against its critical value, one
panel per series.

## Usage

``` r
# S3 method for class 'ssu_test_obj'
autoplot(object, ...)
```

## Arguments

- object:

  An object of class `ssu_test_obj`, the output of
  [`ssu_test`](https://kvasilopoulos.github.io/exuber/reference/ssu_test.md).

- ...:

  Further arguments passed to methods. Not used.

## Value

A [ggplot](https://ggplot2.tidyverse.org/reference/ggplot.html)
