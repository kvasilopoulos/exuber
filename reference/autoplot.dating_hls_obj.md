# Plot method for dating_hls() output

Plots each series with vertical markers at the estimated origination,
collapse and recovery dates.

## Usage

``` r
# S3 method for class 'dating_hls_obj'
autoplot(object, ...)
```

## Arguments

- object:

  An object of class `dating_hls_obj`, the output of
  [`dating_hls`](https://kvasilopoulos.github.io/exuber/reference/dating_hls.md).

- ...:

  Further arguments passed to methods. Not used.

## Value

A [ggplot](https://ggplot2.tidyverse.org/reference/ggplot.html)
