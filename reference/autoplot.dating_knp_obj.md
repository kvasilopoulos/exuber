# Plot method for dating_knp() output

Plots each series with vertical markers at the estimated origination and
collapse dates.

## Usage

``` r
# S3 method for class 'dating_knp_obj'
autoplot(object, ...)
```

## Arguments

- object:

  An object of class `dating_knp_obj`, the output of
  [`dating_knp`](https://kvasilopoulos.github.io/exuber/reference/dating_knp.md).

- ...:

  Further arguments passed to methods. Not used.

## Value

A [ggplot](https://ggplot2.tidyverse.org/reference/ggplot.html)
