# Plot method for dating_hlw() output

Plots each series with vertical markers at every estimated origination,
collapse and recovery date.

## Usage

``` r
# S3 method for class 'dating_hlw_obj'
autoplot(object, ...)
```

## Arguments

- object:

  An object of class `dating_hlw_obj`, the output of
  [`dating_hlw`](https://kvasilopoulos.github.io/exuber/reference/dating_hlw.md).

- ...:

  Further arguments passed to methods. Not used.

## Value

A [ggplot](https://ggplot2.tidyverse.org/reference/ggplot.html)
