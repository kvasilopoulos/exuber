# Plot method for radf_recovery() output

Plots each series with vertical markers at the estimated collapse and
recovery dates.

## Usage

``` r
# S3 method for class 'radf_recovery_obj'
autoplot(object, ...)
```

## Arguments

- object:

  An object of class `radf_recovery_obj`, the output of
  [`radf_recovery`](https://kvasilopoulos.github.io/exuber/reference/radf_recovery.md).

- ...:

  Further arguments passed to methods. Not used.

## Value

A [ggplot](https://ggplot2.tidyverse.org/reference/ggplot.html)
