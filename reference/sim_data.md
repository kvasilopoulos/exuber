# Simulated dataset

An artificial dataset containing series simulated from data generating
processes widely used in the literature on speculative bubbles.
`sim_data` holds five series of 100 observations each; `sim_data_wdate`
is the same data with an additional monthly `date` column. Both were
generated by `data-raw/sim-data.R` with `set.seed(1122)`.

## Usage

``` r
sim_data

sim_data_wdate
```

## Format

A tibble with 100 rows and columns `psy1`
([`sim_psy1()`](https://kvasilopoulos.github.io/exuber/reference/sim_psy1.md)),
`psy2`
([`sim_psy2()`](https://kvasilopoulos.github.io/exuber/reference/sim_psy2.md)),
`evans`
([`sim_evans()`](https://kvasilopoulos.github.io/exuber/reference/sim_evans.md)),
`div`
([`sim_div()`](https://kvasilopoulos.github.io/exuber/reference/sim_div.md)),
`blan`
([`sim_blan()`](https://kvasilopoulos.github.io/exuber/reference/sim_blan.md));
`sim_data_wdate` adds a `date` column (monthly from 2000-01-01).

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 100
rows and 6 columns.
