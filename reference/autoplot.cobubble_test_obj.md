# Plot method for cobubble_test() output

Plots the two input series over the sample, with the test statistic and
lag in the title.

## Usage

``` r
# S3 method for class 'cobubble_test_obj'
autoplot(object, ...)
```

## Arguments

- object:

  An object of class `cobubble_test`, the output of
  [`cobubble_test`](https://kvasilopoulos.github.io/exuber/reference/cobubble_test.md).

- ...:

  Further arguments passed to methods. Not used.

## Value

A [ggplot](https://ggplot2.tidyverse.org/reference/ggplot.html)
