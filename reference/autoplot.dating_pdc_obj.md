# Plot method for dating_pdc() output

Plots each series with vertical markers at the estimated origination,
collapse and (where estimated) recovery dates.

## Usage

``` r
# S3 method for class 'dating_pdc_obj'
autoplot(object, ...)
```

## Arguments

- object:

  An object of class `dating_pdc_obj`, the output of
  [`dating_pdc`](https://kvasilopoulos.github.io/exuber/reference/dating_pdc.md).

- ...:

  Further arguments passed to methods. Not used.

## Value

A [ggplot](https://ggplot2.tidyverse.org/reference/ggplot.html)
